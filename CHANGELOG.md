# Changelog

## 1.0.0 — 2026-08-17

- Added installable Python packaging and a `local-agent` command.
- Added a managed workspace for model-created files.
- Disabled local code and shell execution by default with an explicit opt-in.
- Added path-traversal protections for files and projects.
- Added an offline smoke test and expanded standard-library test suite.
- Added CI coverage for Python 3.10–3.12.
- Added security guidance and an MIT license.
- Reworked documentation around verified capabilities and safe operation.
- Added a responsive local web app with chat, status, memory, and project panels.
- Added concurrent request handling with serialized agent state for reliable multi-tab use.
